# Troubleshooting

Common issues, error messages, and solutions to help you resolve problems with WhackerLinkFiveM.

## Installation Issues

### Resource Not Loading

#### Symptoms
- WhackerLinkFiveM not appearing in server resources
- No startup message in server console
- Commands not working

#### Solutions
1. **Check file placement**:
   ```
   resources/
   └── WhackerLinkFiveM/
       ├── fxmanifest.lua
       ├── client/
       ├── server/
       └── configs/
   ```

2. **Verify server.cfg**:
   ```bash
   ensure WhackerLinkFiveM
   ```

3. **Check console for errors**:
   - Look for YAML parsing errors
   - Verify file permissions
   - Check for missing dependencies

#### Error Messages
```
Error parsing YAML file: configs/config.yml
```
**Solution**: Check YAML syntax, ensure proper indentation (spaces, not tabs)

```
Resource 'WhackerLinkFiveM' failed to start
```
**Solution**: Most likely an issue with yml formatting of configs or codeplugs. See above.

### Configuration File Errors

#### Invalid YAML Syntax
```
Error loading codeplugs: YAMLException: bad indentation
```
**Solutions**:
- Use spaces instead of tabs
- Maintain consistent indentation (2 or 4 spaces)
- Validate YAML syntax online
- Check for missing colons or quotes

#### Missing Configuration Files
```
Error loading sites config: ENOENT: no such file or directory
```
**Solutions**:
- Ensure all config files exist in `configs/` folder
- Copy from example configurations  
- Check file naming (case sensitive)

## Connection Issues

### Cannot Connect to WhackerLink Server

#### Symptoms
- "Site trunking" message persists
- No voice communication
- Radio shows "out of range" constantly

#### Diagnostic Steps
1. **Verify server address in codeplug**:
   ```yaml
   systems:
     - name: "Main System"
       address: "correct-server-address.com"
       port: 3000
   ```

2. **Test network connectivity**:
   ```bash
   # From server machine, test connection
   telnet your-whackerlink-server.com 3000
   ```

3. **Check authentication key**:
   ```yaml
   systems:
     - name: "Main System"
       authKey: "correct-auth-key-here"
   ```

#### Common Connection Errors

```
WebSocket connection failed
```
**Causes**:
- WhackerLink server is offline
- Firewall blocking connection
- Incorrect server address/port
- Invalid authentication key

**Solutions**:
- Verify WhackerLink server is running
- Check firewall rules
- Confirm server address and port
- Verify authentication key matches server

### Authentication Failures
```
Authentication failed: Invalid auth key
```
**Solutions**:
- Check auth key in codeplug matches server
- Ensure no extra spaces in auth key
- Verify server-side authentication settings

## Audio Issues  

### No Voice Communication

#### PTT Not Working
**Symptoms**: PTT key doesn't transmit, no TX indicator

**Solutions**:
1. **Check your FiveM keybind configuration**:

2. **Ensure the microphone you're using is set as the default recording device in Windows**:
   - Right-click sound icon → Sounds → Recording tab
   - Set your microphone as default
   - Test microphone functionality

3. **Verify microphone permissions**:
   - Allow FiveM microphone access
   - Test microphone in other applications
   - Check Windows privacy settings

4. **Confirm radio setup**:
   ```bash
   /set_rid 1234
   /set_codeplug your-codeplug
   ```

#### Can't Hear Others
**Symptoms**: Others can hear you, but you can't hear them

**Solutions**:
1. **Check volume settings**:
   - Increase radio volume with volume buttons
   - Check FiveM audio settings
   - Verify system audio levels

2. **Test different channel**:
   - Switch zones/channels
   - Verify others are on same talkgroup

3. **Ensure other persons microphone is working properly**:
   - Ask others to test their microphone
   - Check if others can hear each other

## Error Messages Reference

### Error Code Reference

| Code | Description | Solution |
| ---- | ----------- | -------- |
| Fail 01/00 | Unhandled error | Catchall for unexpected errors, turn off radio and set RID and codeplug again. Turn radio back on. |
| Fail 01/01 | Exception thrown in network comms | Power cycle radio. If persists, set RID and codeplug again, then turn radio back on. |
| Fail 01/10 | Unhandled internal exception | Common with improper master system configuration. Set RID and codeplug again, then turn radio on. If persists, check all configs and network communication. |
| Fail 01/12 | Caught power on exception | Power cycle radio, ensuring to set RID and codeplug again before turning back on. |
| Fail 01/82 | Invalid codeplug | You have either not set your codeplug or the codeplug is invalid. Use set_codeplug again and power cycle radio. If persists, check codeplug yml. |
| Fail 01/83 | Invalid radio ID | You have not set your RID. Turn radio off and use /set_rid command. Turn radio back on. |
| Fail 01/84 | Scan exception | Check scan settings in codeplug and ensure proper configuration. |
| Fail 00/00 | Unknown power failure | Something went wonkybonky with the power-on cycle. Power cycle radio, ensuring to set RID and codeplug again before turning back on. |

## Getting Help

### Before Seeking Support

1. **Check this troubleshooting guide**
2. **Verify all configuration files**
3. **Test with minimal configuration**
4. **Check server and client console logs**
5. **Test with other players/resources disabled**

### Information to Provide

When asking for help, include:
- WhackerLinkFiveM version
- WhackerLinkServer version
- FiveM server version
- Error messages (exact text)
- Configuration files (sanitized)
- Steps to reproduce the issue
- Server/client console logs

### Support Channels

- **Discord Community**: [WhackerLink Discord](https://discord.gg/FeQMmc33VV)
- **GitHub Issues**: [WhackerLinkFiveM Issues](https://github.com/WhackerLink/WhackerLinkFiveM/issues)

### Creating Bug Reports

Include in your GitHub issue:
1. **Clear description** of the problem
2. **Steps to reproduce** the issue
3. **Expected vs actual behavior**
4. **Configuration files** (remove sensitive data)
5. **Console logs** (server and client)
6. **Environment details** (OS, FiveM version, etc.)
